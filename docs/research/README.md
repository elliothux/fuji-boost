## 记录方式

- 正文写入 `docs/research/<领域>/YYYY-MM-DD.md`；同一领域、同一天的进展追加到该文件，以时间或主题开新小节。
- 跨领域记录选择一个主要领域，其他领域用链接引用，避免复制同一份流水。
- 根目录 `RESEARCH.md` 只保留导航；本索引只维护入口和日期，不追加实验流水。
- `undated.md` 保留原文未明确标注日期的资料；新记录使用实际日期。
- 结论区分原始观察、源码推断和未知项；更正记录说明原结论与新证据。
- 大型二进制、原始导出及运行日志继续放 `research/`，正文使用相对链接引用。
